# UI/UX Design System Guidelines

Khi người dùng yêu cầu thiết kế giao diện (UI) hoặc trải nghiệm (UX):
1. Tham chiếu skill ui-ux-pro-max, design, design-system và ui-styling.
2. Tuân thủ bảng màu có cơ sở và độ tương phản WCAG AA tối thiểu 4.5:1.
3. Typography phân cấp rõ ràng (H1, H2, Body, Caption).
4. Áp dụng các mẫu ResourceDictionary, Modern Dark/Light theme cho WPF/.NET.
